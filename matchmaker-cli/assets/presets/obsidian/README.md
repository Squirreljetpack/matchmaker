A TUI for browsing Obsidian notes:

- ob-files: browse files
- ob-vaults: browse vaults
- ob-open: open files in obsidian
- ob-inbox: append to special (inbox) notes

Requires:

- f:ist
- Edit and run `ob-vaults -r` beforehand to populate vaults (suggestion: include this command in a shell startup or cache reset script).
